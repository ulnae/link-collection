# link-easy 功能清单及操作使用说明

## 一、插件简介

**link-easy** 是一款浏览器（Chrome / Edge 等 Chromium 内核）插件，用于一键识别当前页面中的六大类资源链接，并通过 iOS 风格悬浮窗分类展示、复制。

技术实现：TypeScript + Vite（现代构建链路），UI 采用 Shadow DOM 隔离注入，iPhone 设计语言（毛玻璃、分段控制器、圆角胶囊按钮）。

## 二、功能清单

| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F1 | 悬浮按钮 | 页面右侧悬浮一个渐变蓝色圆形按钮，始终置于页面最顶层 |
| F2 | 按钮拖拽 | 按住按钮可拖拽调整位置，自动吸附在视口范围内；位置记忆（刷新后保持） |
| F3 | 点击识别 | 单击按钮（不拖动）开始识别，识别中按钮图标旋转提示 |
| F4 | 六大类链接识别 | ① 图片资源（含 img/picture/srcset/svg image/背景图）② 音频资源 ③ 视频资源 ④ 嵌入浏览上下文/页面（iframe/frame）⑤ 脚本资源（js）⑥ 外链样式资源（css） |
| F5 | 仅 http/https | 所有识别结果仅保留 http/https 协议的绝对链接，相对地址自动解析为绝对地址并去重 |
| F6 | 悬浮窗弹出 | 识别完毕后弹出 iOS 风格悬浮窗，默认宽高为屏幕宽高的一半，居中显示，带弹入动画 |
| F7 | 悬浮窗拖拽 | 按住悬浮窗头部可拖拽移动位置（红/黄圆点按钮除外） |
| F8 | 悬浮窗缩放 | 拖拽右下角缩放手柄（蓝色斜线图标，悬停高亮）可调整宽高（最小 360×240，最大为屏幕的 90%） |
| F9 | 最小化/恢复 | 点击头部黄点（− 号图标）最小化为标题栏，再点恢复 |
| F10 | 关闭 | 点击头部红点（× 号图标）关闭悬浮窗，可再次点击悬浮按钮重新识别 |
| F11 | Tab 分类切换 | 悬浮窗内为 6 个分类的分段控制器（Segmented Control），每个 tab 显示该类链接数量，点击切换列表 |
| F12 | 链接列表 | 列表左侧显示链接，超长自动省略号（可悬停看全文，可点击新标签打开）；右侧固定宽度「复制」按钮 |
| F13 | 一键复制 | 点击「复制」复制该条链接到剪贴板，底部弹出 iOS 风格 Toast「已复制到剪贴板」 |
| F14 | 空状态提示 | 某分类无链接时显示放大镜图标与提示文案 |
| F15 | 图片预览 | 「图片资源」tab 下每条链接左侧显示对应图片的缩略预览（懒加载、跨域不泄露 referrer，加载失败显示「失效」占位） |

## 三、操作使用说明

### 1. 安装（开发者模式加载已解压的扩展程序）

1. 执行 `npm install` 安装依赖；
2. 执行 `npm run build`，生成 `dist/` 目录（开发时可用 `npm run dev` 监听变更自动构建）；
3. 打开 Chrome，访问 `chrome://extensions/`，右上角开启「开发者模式」；
4. 点击「加载已解压的扩展程序」，选择本项目的 `dist` 目录；
5. 打开任意网页，页面右侧即可看到蓝色悬浮按钮。

> 说明：Chrome 已禁止拖拽安装商店外的 crx 文件，因此本插件采用「加载已解压的扩展程序」方式安装使用；修改代码后重新构建，在扩展页面点击刷新图标即可生效。

### 2. 开发调试

```bash
npm run dev     # 监听 src 变更，自动构建到 dist
npm run build   # 单次构建
```

修改 `src/` 下代码保存后，回到 `chrome://extensions/` 页面点击插件的「重新加载」按钮，刷新目标网页即可看到效果。

### 3. 日常使用

1. **识别**：打开目标网页 → 单击悬浮按钮 → 按钮图标旋转表示识别中 → 识别完成自动弹出悬浮窗；
2. **切换分类**：点击悬浮窗顶部分段控制器的 6 个 tab，查看对应类别链接；
3. **复制**：点击任意条目右侧的「复制」按钮；
4. **打开链接**：点击列表中的链接文本，在新标签页打开；
5. **调整窗口**：拖动头部移动位置；拖动右下角手柄调整宽高；黄点最小化、红点关闭；
6. **调整按钮**：按住悬浮按钮拖到喜欢的位置，位置会自动记住。

## 四、项目结构

```
link-easy/
├── manifest.json          # Chrome 插件清单（MV3）
├── package.json           # 依赖与脚本（build / dev / typecheck）
├── vite.config.ts         # Vite 构建配置（单入口 IIFE + 拷贝 manifest）
├── tsconfig.json          # TypeScript 配置
├── src/
│   ├── content.ts         # 内容脚本：识别逻辑 + 悬浮按钮 + 悬浮窗
│   └── style.ts           # iOS 风格样式（注入 Shadow DOM）
├── dist/                  # 构建产物（用于加载已解压扩展）
└── FEATURES.md            # 本文档
```

## 五、常见问题

**Q：识别不到某些链接？**
插件只识别 DOM 中的静态资源链接（img/audio/video/iframe/script/link 标签及背景图）。由 JS 运行时动态创建且扫描时尚未插入的元素不会被统计，可等页面加载完成后再点一次识别。

**Q：悬浮窗被页面遮挡？**
UI 位于 Shadow DOM 且 z-index 取最大值（2147483647），正常情况始终在最上层；若页面使用了同样的超大 z-index，可最小化悬浮窗后拖动位置避开。

**Q：为什么有些分类是 0 条？**
当前页面确实不存在该类资源，属正常现象。
